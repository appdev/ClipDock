# ClipDock 0.1.16

## macOS 0.1.16（Build 15）

- 新增卡片重命名：右键选择“重命名”或按 ⌘R，在卡片标题处编辑。
- 回车或点击其他位置保存，Esc 取消；清空名称恢复默认标题。
- 自定义名称持久保存，支持中文、拼音搜索，保留原有剪贴板内容和排序。
- 修复搜索框文字、占位文字和光标的垂直对齐。
- 修复重命名回车提交时的旧标题回显和卡片闪烁，保存失败时恢复原名。

## Windows 0.2.2

- 更新共享存储核心，兼容自定义卡片名称的保存、搜索及数据库升级。
- 保留现有 Windows 面板交互；本次卡片内重命名交互仅在 macOS 提供。

## 安装包

- macOS：Apple Silicon（arm64）与 Intel（x86_64）DMG。
- Windows：x64 EXE 与 MSI。

首次启动会自动将数据库升级到 schema 18。需要回退旧版时，请使用升级前的数据库备份。
