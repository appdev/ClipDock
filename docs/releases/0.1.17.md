# ClipDock 0.1.17

macOS 与 Windows 均支持卡片重命名。

## Windows 0.2.3

- 右键选择“重命名”，或选中卡片按 F2 / Ctrl+R，在卡片标题处编辑。
- 回车或点击其他位置保存，Esc 取消；清空名称恢复默认标题。
- 保存过程中保持新标题显示，避免旧名称闪回；保存失败时恢复最近成功保存的名称并提示。
- 支持中文输入法，确认候选词时不会误提交重命名。
- 自定义名称重启后保留，支持中文和完整拼音搜索，不改变原始剪贴内容。
- 新捕获的卡片使用数据库记录 ID，可立即重命名并保存；重复复制后保留名称。

## macOS 0.1.17（Build 16）

- 保留上一版本的卡片重命名、搜索框垂直居中及回车提交防闪烁修复。
- 本次更新统一发布版本，macOS 功能与 0.1.16 相同。

## 安装包

- macOS：Apple Silicon（arm64）与 Intel（x86_64）DMG。
- Windows：x64 EXE 与 MSI。

沿用 schema 18，从上一版本升级无需新增数据库迁移。
