# ClipDock 0.1.20

- Fix macOS login-item launch detection so automatic login startup keeps all initial windows hidden.
- Preserve opening Preferences on manual launch or when reopening the application.
- Cover the modern Apple Event launch reason, legacy startup argument, manual startup and reopen behavior with regression tests.

This release also includes the previously unreleased 0.1.19 clipboard-core integration: lightweight history lists, shared Rust policies, coordinated asset cleanup, asynchronous preference updates and preservation of Windows rename drafts while scrolling.

macOS build: 19. Windows application version: 0.2.5.
